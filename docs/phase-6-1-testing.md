# Phase 6.1 测试说明

本阶段只验收三件事：成片时长、界面观感、录制时窗口行为。

## 启动

在 `apps/desktop` 目录运行：

```powershell
npm run tauri dev
```

## 测试 1：时长与时间连续性

1. 打开 Windows 时钟或任意在线秒表，让秒数出现在被录制画面中。
2. 开始录制，持续 20 到 30 秒；期间移动并点击鼠标，让成片产生至少两次推进和恢复。
3. 使用快捷键结束录制，等待 FocusFlow 重新出现并完成渲染。
4. 分别播放原始 `.mp4` 与 `.final.mp4`。
5. 对比两个文件的总时长；允许编码造成约 0.1 秒级误差，不应再明显缩短。
6. 观察成片里的秒表：数字应连续前进，不应出现从 1 秒突然跳到 4 秒的情况。

## 测试 2：隐藏与恢复

1. 点击开始录制后，FocusFlow 应立即从桌面隐藏。
2. 使用设置的单键快捷键结束录制。
3. FocusFlow 应自动重新显示，并出现在其他普通窗口前面。
4. 大约 1.2 秒后应用会取消永久置顶，避免一直遮挡其他软件。

## 测试 3：新版 UI

重点查看：

- 主操作是否一眼可见；
- 录制状态、计时和处理状态是否清楚；
- 保存位置与快捷键设置是否容易理解；
- 最近输出文件是否方便确认；
- 在 1120 × 720 默认窗口下是否有遮挡、溢出或文字截断。
