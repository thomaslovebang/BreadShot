# Security policy

## Supported versions

BreadShot is currently an early public alpha. Security fixes are provided for the latest GitHub release and the current `main` branch. Older installers may not receive backports.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose recordings, microphone audio, local files, update channels, or arbitrary command execution.

Use [GitHub private vulnerability reporting](https://github.com/thomaslovebang/BreadShot/security/advisories/new) with:

- the affected version or commit;
- reproduction steps and expected impact;
- whether user interaction is required;
- any suggested mitigation;
- only sanitized attachments.

You should receive an initial acknowledgement within seven days. We will validate the report, coordinate a fix and disclosure, and credit the reporter unless anonymity is requested. BreadShot does not currently offer a paid bug bounty.

## Privacy-sensitive reports

Never attach a real recording, mouse trace, custom cursor, log, or screenshot containing passwords, personal data, proprietary code, or private communications. Reproduce with disposable sample data whenever possible.
